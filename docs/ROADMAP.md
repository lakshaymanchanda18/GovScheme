# GovScheme Roadmap

## Phase 1: Stability + Demo Readiness
- Fix CORS and API alignment for reliable data fetch.
- Add health check and clearer error handling.
- Seed consistent scheme data for demo.
- Deliver AI-assisted eligibility scoring with explainable output.

## Phase 2: Data Partnerships + Real Integrations
- Integrate official scheme portals/APIs (where available).
- Add schema mapping and adapter layer for multiple departments.
- Improve data freshness with scheduled sync jobs.

## Phase 3: Community Access Expansion
- Voice assistant in regional languages.
- Offline/low-bandwidth mode and kiosk-friendly UI.
- Beneficiary feedback loop and impact analytics dashboards.
